Marcar los dos lados del corte

Clic corto sobre una cámara naranja: añadir/quitar. Arrastrar sigue girando. Las marcas no conectan ni mueven cámaras.

Selecciona cámaras de un lado; después cambia al otro.

Si se superponen varios centros, usa esta lista. ID de vista ≠ ID de intrínsecos.

    Las marcas se guardan solo en este navegador por dataset/componente; no editan la sparse. No se descargaron fotos originales.

    Cada componente tiene su propio sistema de coordenadas. Cambiar de componente centra su vista; no implica que estén alineados entre sí.

    ¿Se puede corregir?

    Separación no significa necesariamente geometría rota. Podemos buscar conexiones entre componentes o colocar sus sparse manualmente. Unir puntos sin validar escala y cámaras no corrige la reconstrucción.

    Este visor no modifica puntos, cámaras ni resultados. Las cámaras se muestran como puntos naranjas. La vista muestra hasta 250.000 puntos por componente, muestreados; los originales se conservan completos.
